Admin Dashboard Tabs

Visitors Tab (shown above)

  • Quick stats bar (checked in now, today, week, workers)
  • Searchable, filterable visitor table
  • Date range picker
  • CSV export
  • View license photo per visitor
  • Green "In" / time "Out" status badges

Workers Tab

  • Add/edit/remove workers
  • Worker name, email, department/title
  • Email used for visit notifications

Agreements Tab

  • Upload company NDA/agreement PDF
  • Toggle agreement on/off for kiosk
  • View signed agreements per visitor
  • Download signed copies

Settings Tab

  • Company logo upload
  • Primary brand color picker
  • Welcome message
  • Toggle kiosk steps (license photo, NDA)
  • Kiosk URL for easy sharing
